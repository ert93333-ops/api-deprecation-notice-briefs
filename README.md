# API Deprecation Notice Briefs

Static MVP for checking pasted public-safe API deprecation, migration, and changelog notes before a customer notice goes out.

## Offer

Paste API change notes. Generate a copyable customer notice brief and internal launch handoff covering:

- missing effective date or deadline
- missing affected endpoint, field, version, or SDK scope
- breaking versus non-breaking ambiguity
- missing customer impact summary
- missing migration steps
- missing docs or support path
- missing owner or escalation path
- missing customer segment or plan impact
- risky vague language such as "soon", "later", or "deprecated" without action
- overpromise or backwards-compatibility ambiguity
- missing internal follow-up decision

## Conversion Path

Payments are not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.

## Constraints

- No GitHub API.
- No repository cloning.
- No OpenAPI parser.
- No API gateway integration.
- No docs CMS integration.
- No CRM or help-desk API.
- No email sending.
- No customer notice publishing.
- No legal, contract, SLA, or compliance advice.
- No external database.
- No backend required.
- Pasted samples stay browser-local.
